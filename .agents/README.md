# .agents - GI-OCR

Instrucciones locales versionadas para agentes.

## Estructura

- skills/: capacidades operativas reutilizables.
- prompts/: prompts locales versionados.

## Regla

Los agentes deben leer estos archivos como contenido del repositorio.

No deben asumir que existe una herramienta llamada Skill(...) si el entorno no la ofrece.
