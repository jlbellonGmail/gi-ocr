# .specify - GI-OCR

Plantillas y reglas reutilizables para Spec-Driven Development.

Las specs concretas de tareas o features deben vivir en specs/.

## Templates esperados

- templates/spec-template.md
- templates/plan-template.md
- templates/acceptance-template.md
- templates/evidence-template.md

## Regla

Durante una feature funcional no se debe hacer bootstrap de instrucciones.

Si falta una ruta critica, la tarea debe bloquearse y reportar recovery.
